agino-gpu 快捷面板与控制中心“显卡”页

以 157（Arrow Lake 集显 + RTX 5080 Laptop，带 MUX）为例，按 DDE V25 / DTK 的外观画，浅色深色跟随系统。点击可以操作：进入快捷面板的下级页面、选模式、在控制中心添加应用。上方的场景切换展示各种状态。只是界面稿，不代表最终像素。

相对草案 1 的改动（按你的意见）
  • 去掉单独的托盘图标。多显卡时，快捷面板里加一个与 Wi-Fi、蓝牙同样的两格磁贴，点进去是面板内的下级页面，在里面选模式。
  • 控制中心“添加应用”不再弹出对话框，改为“显卡”页里的下级页面。
  • 除了系统已安装的应用，还可以浏览文件，指定任意程序（例如解压即用的游戏、AppImage）。
  • 没有托盘图标后，“上次开机切换失败”改用系统通知提醒。

磁贴（两格，与 Wi-Fi、蓝牙并排）

  • 只在检测到两块及以上显卡时出现；单显卡机器上没有这个磁贴，任务栏也不放任何图标。
  • 左侧圆形图标表示当前模式；标题“显卡”；副标题是当前模式和独显状态的短写，例如“混合 · 休眠”“混合 · 工作中”（两格磁贴留给副标题的宽度与 Wi-Fi 相同，约 6 个汉字）。待生效时副标题变黄（“重启后改集显”），上次切换失败时变红（“切换失败”）。
  • 整块磁贴点击都进入下级页面。没有“一点就开关”的动作，因为切换模式要注销或重启。

下级页面（在快捷面板内展开，和 Wi-Fi 列表一样，“‹”返回）

  1. 提示条（只在需要时出现）：待注销/待重启、外接显示器警告、上次开机失败、Flatpak 运行时缺失。
  2. 模式：单选，右侧标出生效代价。点一个模式只是保存，提示条给出“撤销 / 稍后 / 立即重启”。不支持的模式不显示。切换需要管理员授权。
  3. 正在使用独显的应用：只读 /proc，不唤醒独显；页面打开时每 2 秒刷新。
  4. 底部：“显卡设置”打开控制中心的“显示 → 显卡”。
系统通知

上次开机切换失败

登录后由快捷面板插件发出一次（插件随 dde-tray-loader 在登录时加载，不需要用户打开面板）。点“知道了”后不再提醒；磁贴副标题保持红色直到下次成功切换或清除。

显卡模式没有切换成功
上次开机时“独显优先”没有生效，已自动回到“混合”。原因：图形服务未能使用 NVIDIA 显卡。
控制中心

“显示”页里的入口

放在“显示”页现有设置的最后（权重 120），只在多显卡机器上出现。右侧显示当前模式，待生效时显示“重启后改为集显”。

控制中心

显示 → 显卡，以及下级页面“添加应用”

在“按应用使用独显”里点“添加应用”进入下级页面（顶部路径变为 显示 › 显卡 › 添加应用），点路径里的“显卡”或“取消”返回。在下级页面里可以勾选已安装的应用，也可以点“浏览…”指定文件。

“显卡”页的五组

  • 显卡：每块卡的名称、驱动和版本、接了哪些显示器、独显当前状态（只读 sysfs）。
  • 显卡模式：四张卡片，写清效果和代价；当前生效的标“当前”，已保存未生效的标“重启后生效”。
  • 按应用使用独显：只在混合模式下起作用，其他模式下整组置灰并说明原因。规则分两种：系统里的应用（按应用标识），和从文件添加的程序（按文件路径，标“文件”）。每条可选“电池供电时暂停”。
  • 应用兼容：只列出检测到的情况（没装 Flatpak 就不显示 Flatpak 那一行）。
  • 高级：独显运行时休眠是否在工作、命令行用法。

“添加应用”下级页面

  • 系统里的应用：来自应用管理器的列表，可搜索、多选；已添加的标“已添加”且不能重复勾选。
  • 从文件添加：“浏览…”打开系统的文件选择窗口，可选可执行文件、AppImage、脚本或 .desktop 文件。选中 .desktop 时按应用处理；选中程序文件时按路径记规则。
  • 按路径的规则何时生效：从启动器、任务栏，或任何 Exec 指向这个文件的桌面入口启动时生效（应用管理器补丁按程序路径匹配）。在文件管理器里双击、或从终端直接运行时不生效，终端里用 agino-gpu-run。为此页面上可选“在启动器里创建入口”，默认勾选，名称取自文件名，可改。
  • 底部“添加”保存并回到“显卡”页；“取消”直接返回。
