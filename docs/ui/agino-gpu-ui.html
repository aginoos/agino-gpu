agino-gpu 托盘插件与控制中心“显卡”页

以 157（Arrow Lake 集显 + RTX 5080 Laptop，带 MUX）为例。按 DDE V25 / DTK 的外观画，浅色深色跟随系统。模式可以点击，用来演示切换流程；上方的场景切换展示各种状态下的样子。只是界面稿，不代表最终像素。

场景
托盘

任务栏图标

一个图标同时表示两件事：当前模式（图形）和独显此刻的状态（右下角圆点）。鼠标悬停显示文字提示，例如“混合模式 · 独显休眠中”。

托盘

点击图标后的弹窗

14:32
10月26日

从上到下

  1. 标题行：图标、“显卡”、当前生效的模式和独显状态。
  2. 提示条（只在需要时出现）：待注销/待重启、切换警告、上次开机失败、Flatpak 运行时缺失。按钮直接执行注销、重启或撤销。
  3. 模式：单选列表，右侧标出生效代价（立即、需注销、需重启）。点一个模式只是保存，提示条给出“立即重启 / 稍后”。机器不支持的模式不显示（例如没有 MUX 就没有“独显直连”）。
  4. 正在使用独显的应用：读 /proc，不唤醒独显；弹窗打开时每 2 秒刷新。
  5. 底部：“显卡设置”打开控制中心的“显示 → 显卡”。

切换模式需要管理员授权（polkit，同一会话内记住一段时间）。

托盘

快捷面板磁贴

占两格（与“护眼模式”等同级）。显示模式和独显状态；点击展开上面的弹窗，不在磁贴上直接切换，因为切换要注销或重启。

控制中心

“显示”页里的入口

放在“显示”页现有设置的最后（权重 120）。只在双显卡机器上出现。右侧显示当前模式，待生效时显示“重启后改为集显”。

控制中心

显示 → 显卡

五个分组

  • 显卡：每块卡的名称、驱动和版本、接了哪些显示器、独显当前状态。状态只读 sysfs。
  • 显卡模式：四张卡片，写清楚效果和代价（耗电、需注销/重启、外接口限制）。当前生效的标“当前”，已保存但未生效的标“重启后生效”。
  • 按应用使用独显：只在混合模式下起作用，其他模式下整组置灰并说明原因。每条规则可选“电池供电时暂停”。下面列出推荐应用（默认不启用）。
  • 应用兼容：只列出检测到的情况。没装 Flatpak 就不显示 Flatpak 那一行；没装 Steam 就不显示 32 位库。
  • 高级：独显运行时休眠是否在工作（被省电设置关掉时说明原因）、上次切换失败的记录、命令行用法 agino-gpu-run。
